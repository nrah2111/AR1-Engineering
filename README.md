# ARONE Engineering — เว็บไซต์บริษัท

เว็บไซต์แบบ static (HTML / CSS / JavaScript ล้วน ไม่มีฐานข้อมูล)
โฮสต์บน GitHub Pages ได้ทันทีโดยไม่ต้องตั้งค่าอะไรเพิ่ม

## หน้าเว็บ

| ไฟล์ | หน้า |
|---|---|
| `index.html` | หน้าแรก — วิดีโอโรงงาน, หมวดหมู่, สินค้าแนะนำ, แกลเลอรี, ติดต่อ |
| `categories.html` | หมวดหมู่สินค้า — เลือกตามประเภท / ระบบเกลียว / รูปแบบ |
| `shop.html` | สินค้าทั้งหมด — ค้นหาแบบทันที + ตัวกรอง |
| `product.html` | รายละเอียดสินค้า (เปิดด้วย `product.html?id=SPC`) |
| `contact.html` | ติดต่อเรา + แผนที่ |

## แก้ไขข้อมูลสินค้า

สินค้าทั้งหมดอยู่ใน **`assets/products.js`** ไฟล์เดียว — แก้ที่นี่แล้วทุกหน้าอัปเดตตาม

```js
{
  id:"JM-BMT-90",                       // รหัสรุ่น (ใช้ใน URL ด้วย)
  cat:"adapter",                        // ตระกูลสินค้า
  shape:"elbow", shapeName:"ข้องอ 90°", // รูปแบบ
  img:"assets/products/AD-JM-BMT-90.png",
  name:"...", price:null,               // price:null = แสดง "สอบถามราคา"
  lead:"...", specs:{...}, feats:[...]
}
```

- `AR1_CATEGORIES` — ตระกูลสินค้าที่แสดงบนหน้าหมวดหมู่
- `AR1_THREADS` — ระบบเกลียว ถอดรหัสจากรหัสรุ่นอัตโนมัติ (JM → JIC 37°, BMT → BSPT ฯลฯ)

## แก้ไขข้อมูลติดต่อ

อยู่ใน `assets/app.js` ด้านบนสุด (`LINE`, `FB`) และในการ์ดติดต่อของ
`index.html` / `contact.html`

## หมายเหตุ

- `.nojekyll` จำเป็นสำหรับ GitHub Pages — ห้ามลบ
- รูปสินค้าตัดมาจากไฟล์แคทตาล็อก ความละเอียดต้นฉบับต่ำ
  ควรถ่ายรูปสินค้าจริงมาแทนเมื่อสะดวก
- ยังไม่มีข้อมูล **ราคา** และ **ขนาด** ของกลุ่ม Adapter (52 รายการ)
- กลุ่มหัวสาย GJS (10 รายการ) ยังไม่มี **สเปกละเอียด/แบบ (Drawing)** — จะเพิ่มภายหลัง
