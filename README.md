# ARONE Engineering — เว็บไซต์บริษัท

เว็บไซต์แบบ static (HTML / CSS / JavaScript ล้วน ไม่มีฐานข้อมูล)
โฮสต์บน GitHub Pages ได้ทันทีโดยไม่ต้องตั้งค่าอะไรเพิ่ม

## หน้าเว็บ

| ไฟล์ | หน้า |
|---|---|
| `index.html` | หน้าแรก — วิดีโอโรงงาน, หมวดหมู่, สินค้าแนะนำ, แกลเลอรี, ติดต่อ |
| `categories.html` | หมวดหมู่สินค้า |
| `shop.html` | สินค้าทั้งหมด — ค้นหาแบบทันที + ตัวกรอง |
| `product.html` | รายละเอียดสินค้า (เปิดด้วย `product.html?id=GJS-0404-B`) |
| `contact.html` | ติดต่อเรา + แผนที่ |

## แก้ไขข้อมูลสินค้า

สินค้าทั้งหมดอยู่ใน **`assets/products.js`** ไฟล์เดียว — แก้ที่นี่แล้วทุกหน้าอัปเดตตาม

สินค้าปัจจุบัน: หัวสายไฮดรอลิค **GJS** 5 ขนาด (-04, -06, -08, -12, -16) × 2 ผิวเคลือบ
(Brass-tone / Silver-tone) = 10 รายการ สร้างอัตโนมัติจาก generator ใน products.js

- `img` — รูปสินค้า (assets/products/)
- `dwg` — รูปแบบ/สเปก แสดงในแท็บ "แบบ (Drawing)"
- `specPdf` — ไฟล์ PDF สำหรับปุ่มดาวน์โหลดสเปก (assets/specs/)
- `price:null` = แสดง "สอบถามราคา"

## แก้ไขข้อมูลติดต่อ

อยู่ใน `assets/app.js` ด้านบนสุด (`LINE`, `FB`) และในการ์ดติดต่อของ
`index.html` / `contact.html`

## สี / ธีม

กำหนดที่ `:root` ใน `assets/styles.css`

- ส้มแบรนด์ `#F26C25` — พื้นปุ่ม ไอคอน และตัวอักษรบนพื้นเข้ม
- ส้มเข้ม `#B8470C` — ตัวอักษรขนาดเล็กบนพื้นสว่าง (ค่าคอนทราสต์ผ่านมาตรฐาน)
- เทาโลโก้ `#848484` · ถ่าน `#2B2B2E`

## หมายเหตุ

- สเปก GJS อ้างอิงจากแคทตาล็อกประเภท GBFS (BSPP Female Inverted Cone Swivel Nut)
- ราคายังไม่ระบุ — แสดง "สอบถามราคา" ทุกรายการ
